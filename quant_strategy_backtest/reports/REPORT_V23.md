# v2.3 优化报告 — 日内派生微观结构特征（C-lite）

**目的**：测试从日线 OHLC 派生、与现有宏观信号正交的微观结构特征，在免费数据下做 8 年回测。

| 候选 | 特征 | 计算（基于 QQQ）|
|---|---|---|
| **(F) 收盘强度 CLV** | 当日收在区间何处（买卖压力）| `((C-L)-(H-C))/(H-L)` 10 日均 → sigmoid |
| **(G) 隔夜跳空动量** | 机构隔夜累积净买入足迹 | 10 日累积 `open/prev_close-1` → sigmoid |
| **(H) 振幅扩张风险** | 短期波动 > 长期波动 = risk-off | `mean(range,5)/mean(range,60)` → sigmoid |

**消融设计**：5 变体，基线 = v2.1b（信用利差版），微观特征均在 QQQ 上计算（比 TQQQ 噪音小）。

## 2. 这次找到了根本原因：等权平均稀释了 alpha 信号

观察 `results/v23_micro_scores.png`：三个微观特征分数都在 **0.5 附近高频震荡**，没有 VIX/信用/趋势那种"持续数月的区间结构"。

### 稀释机制（关键洞察）

当前 composite = **N 个信号的等权平均**。每加一个信号，权重变成 1/N：

```
v2.1b:  composite = mean(VIX_lvl, VIX_trend, rate, trend, mom, curve, credit)   # 7 个
                  = (高信念信号们) / 7

v2.3:   composite = mean(上述 7 个 + CLV + gap + range)                          # 10 个
                  = (高信念信号们 + 3 个 ~0.5 噪音) / 10
```

微观特征大部分时间 ≈ 0.5（中性噪音），把 composite **拉向 0.5**，**削弱了真正携带 alpha 的信号（信用 + 趋势 + 动量）的信念强度**。

### 2021 年的直接证据

| 变体 | 2021 收益 |
|---|---:|
| v2.1b（信用把 composite 推过 TQQQ 档）| **+26.55%** |
| v2.3a（+CLV 稀释）| −4.48% |
| v2.3b（+gap 稀释）| −4.51% |
| v2.3c（+range 稀释）| +0.66% |

信用利差在 2021 的贡献被微观噪音稀释掉，composite 从 TQQQ 档（>0.75）跌回 QLD 档，重演了 v2 的 2021 漏跑。

**10 个候选，2 个有效（命中率 20%）。最近 8 个"加信号"候选连续 7 个失败**（仅信用利差成功）。

**结论**：在"等权平均信号"这个架构下，v2.1b 是稳健的局部最优。继续加信号，每个新信号都会稀释已有 alpha，边际收益为负。

---

## 4. 这意味着什么 — 两条真正的前进路径

信号叠加已死。剩下两条有意义的路径：

### 路径 1（架构升级，有过拟合风险）：信号加权
- 不再等权平均，而是给信号赋予不同权重
- 问题：权重必须从历史拟合 → **高过拟合风险**
- 若要做，必须用 walk-forward 滚动估计权重 + 严格 OOS，否则不可信

### 路径 2（不同机制，推荐）：跳出信号维度
- **A. walk-forward 验证**：不再优化，给 v2.1b 的 Sharpe 0.93 一个跨区间稳健性认证
- **B. 期权尾部对冲**：用独立机制（而非信号）解决 2022 类深跌

---

## 5. 强烈建议：锁定 v2.1b，转向 walk-forward 验证

理由：
1. 连续两轮消融（v2.2 + v2.3，共 6 个候选）全部失败，数据已明确告知信号叠加到顶
2. v2.1b 当前指标（CAGR 19.2%、Sharpe 0.93、DD −25%、OOS Sharpe 1.46）已是可部署水平
3. **在追加任何新机制之前，先验证当前策略的参数稳健性是更负责任的做法** —— 否则我们是在一个未经稳健性认证的基础上继续堆砌

walk-forward 不增加复杂度、不引入过拟合，反而给整个 v2.1b 一个"能不能信"的量化答案。这是从"研究"走向"可部署"的必经一步。
