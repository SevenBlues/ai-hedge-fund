# 策略 v2 — P0 优化对比报告

**改动**：在 v1 基础上引入三项 P0 优化
1. **Sigmoid 平滑信号**：所有指标用 sigmoid 函数映射到 [0,1]，取代 0/1 硬阈值
2. **QLD（2× 纳指）作为中间档**：评分 [0.50, 0.75) 区间持 QLD 而非 TQQQ，避免在震荡市的杠杆复利衰减
3. **漂移带重平衡（drift band）**：单腿目标权重漂移 < 3pp 时不换仓，降低换手

> 第 4 项 **波动率目标层** 也已实现并提供 `use_vol_target=True` 开关，但实测在本策略栈上效果反而不佳（详见 §4），默认关闭。

回测窗口：**2018-05-24 → 2026-05-22 (8.0 年)**, 数据/成本模型与 v1 完全一致。

## 4. 为什么 vol-target 25% 反而不好（诚实记录）

我按 P0 第 1 项也实现了波动率目标层（默认 25%，匹配 QQQ 自然波动）。但实测：

| | v2 无 vol-target | v2 +vol-target 25% |
|---|---:|---:|
| CAGR | 15.85% | **11.99%** ↓ |
| Sharpe | 0.79 | 0.69 |
| Max DD | −24.4% | −22.8% |

vol-target 在 **2019 / 2021** 两个"高 vol 但持续上涨"的年份过度减仓：
- 2019：v2 +21% → +13%
- 2021：v2 +0.2% → −2.4%

**根本原因**：vol-target 不区分上行波动和下行波动，在牛市中也会减仓。本策略已有 6 维评分系统识别风险，再叠 vol-target 是双重保守。

代码中 vol-target 仍保留 (`StrategyV2Config.use_vol_target=False`)，可选开启。

## 5. 改动的过拟合自检

| 维度 | v2 是否引入新调参 | 备注 |
|---|:---:|---|
| Sigmoid 中心 (VIX=25) | ❌ | 是 v1 区间 (20, 30) 的中点 |
| Sigmoid 斜率 | ❌ | 等于阈值带宽的一半 — 唯一定义 |
| QLD 引入 | ❌ | 新增资产，非阈值调优 |
| 三段映射 0.25/0.50/0.75 | ❌ | 均分四等份 — 唯一定义 |
| 漂移带 3% | ⚠ | 行业惯例值，未做网格搜索 |
| vol_target_ann 25% | ⚠ | 匹配 QQQ 自然波动 — 但已默认关闭 |

未在样本上做任何参数搜索；样本外 Sharpe **提升** 而非衰减 (+0.32)，是过拟合的反向证据。
